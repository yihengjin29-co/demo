# 并表风险驾驶舱 · 设计校核与使用说明

## 使用方式

用浏览器打开源码包根目录下的 `index.html` 即可使用。页面为单文件，可离线打开，无需安装或部署。核心用户为集团及国资公司高层领导，两个主体共用同一视图，不设置角色切换。默认完整显示一屏，无下滑内容；具体清单与明细通过弹窗查看。主要面向桌面和大屏，原设计阶段检查过1920×1080、1440×900、1366×768尺寸；本次源码整理未重新进行浏览器视觉验收。窄屏保持整体缩放，不作为移动端办理界面。

首页固定为三层：上层展示机构数、月度黄灯数、月度红灯数和月度重大风险事件数，四项均附较上月数量变化；中层左侧为四家机构的风险插旗矩阵，右侧默认展示5项并表指标及独立的“＋添加指标”卡；下层舆情与重大风险事件分别连续向上循环滚动，窗口可容纳2条完整信息。指标可按机构、风险类型和监测／管控类型自定义多选，超过5项在指标区内分页，整页不增加滚动。信息优先级仍为总体情况、风险位置和重点事项，详细数据通过点击下钻。

所有金额、指标值、阈值、机构监测关系、事件及资讯均为演示数据，不代表上海国际集团、国际AMC、国泰海通、浦发银行或沪农商银行的实际经营状况、控制关系或监管结论。页面没有读取机构真实数据，也不会发送邮件、提示函或机构通知。

## 可体验的交互

1. 切换观察月份，联动展示本月预警、当期指标及趋势。
2. 点击四项纵览，查看机构范围、本月触发的黄灯或红灯事项、重大风险事件完整清单。黄灯、红灯弹窗按“机构、监测类型、指标类型、指标名称、预警日期、当前状态、处置状态、操作”八列展示，按机构、经营／资本／风险、风险类别依次归类排列，并支持前三项分类筛选；操作列可继续查看处置详情。
3. 风险热力图采用无卡片底框的插旗矩阵，按机构分行、风险类型分列。每个坐标点设置底座，旗杆落在对应底座上；红旗、黄旗分别代表红灯、黄灯，旗上数字为该等级当前预警指标数；两种预警并存时在同一底座上展示两面旗。正常用小圆点、缺数用菱形、超期用时钟、未配置用短线区分，不将缺数或未配置解释为正常。矩阵仅保留横向细分隔线，突出需要关注的风险。
4. 按原文档区分两条下钻路径：机构名称进入弹窗A，顶部展示资本与风险概览，按资本指标及八类风险列示指标总数、本月曾预警指标数、当前黄灯、红灯、正常和缺数／超期数量；点击数字可筛选下方指标明细。明细保留全部指标（含经营指标），按监测类型、指标类型、指标名称、当月值、黄灯阈值、红灯阈值、当前状态、处置状态、操作分栏，支持分类、当前状态、月内预警筛选、搜索和20项分页。点击旗帜或风险位置进入弹窗B，仍默认仅列示该机构、原矩阵类别的红黄灯指标，另提供“查看该类别全部指标”。两类清单均同时展示黄灯阈值、红灯阈值及判定方向，可继续查看指标或处置详情。
5. 关键指标区默认展示并表口径的最大行业风险暴露占比、未来30日现金覆盖倍数、资产拨备率、合格资本覆盖率和净利润。点击独立的“＋添加指标”卡，在弹窗中按国泰海通、国际AMC、浦发银行、沪农商银行及并表口径、风险类型、监测／管控类型筛选；同一维度为多选并集，不同维度组合筛选。可多选添加、取消勾选、从已选清单移除、全选筛选结果、清空已选或恢复默认，保存前不影响首页。指标卡明确显示所属机构或并表口径、当月值、灯色及近12月折线图，避免混淆机构单体与并表指标。每页最多5项，添加入口始终可见；点击任一指标可查看12/24/36个月详情。偏好保存在当前浏览器，不修改指标计算规则；切换月份时，未纳入当期范围的机构指标暂不展示，但保留其选择。
6. 点击“核对计算与来源批次”，核对演示计算基准；集中度指标可继续查看共同客户敞口。
7. 预警详情展示识别、下发、回函、整改、复核、办结的六环节轨迹，可下载提示函演示样稿。首页不承担审批或办理操作。
8. 舆情与重大事件以连续匀速移动方式循环展示，首尾衔接，不采用逐条替换或淡入淡出的闪切方式。鼠标悬停、键盘焦点在板块内、打开弹窗或页面处于后台时暂停；支持手动上/下一条和播放/暂停。系统设置为减少动态效果时停止自动滚动，仍可手动切换或打开全部清单。
9. 弹窗支持返回上一级、浏览器前进/后退和Esc关闭；下钻返回时保留观察月份、机构、风险分类、搜索条件及页码，报告打开附件后返回可恢复原阅读位置。关闭后仍回到同一张风险全景视图。
10. 点击月度重大风险事件数量或板块“全部”，按机构、风险类型、事件名称、发生日期、上报日期、关注等级、当前流程环节、处置状态、操作九列展示，支持机构、风险类型、关注等级、处置状态及关键词筛选。跨机构事件在同一行列示牵头与协同机构，选择任一参与机构均可查到，但按事件编号仅计一次。
11. 点击滚动事件或清单“查看报告”，进入完整的示例报告：基本信息、事件经过与原因、影响评估与风险关联、处置方案、当前处置流程、续报与执行进展、复核与办结、报告附件。顶部突出当前环节、状态、办理岗位和下一反馈时限，可通过章节导航跳转。处置方案细分措施、工作内容、责任岗位、完成时限、执行状态和核验材料；流程分六节点，区分已完成、当前与待开展；附件可打开查看文本示例。

### 统计口径

本月黄灯和红灯数量按触发事项去重，并保留触发等级；热力图按当前仍亮灯的指标统计。2026年8月样例为4家机构、黄灯11项、红灯4项、重大风险事件6件，较7月分别增加1家、4项、1项和2件。其中1项黄灯指标已恢复但仍待复核，热力图对应当前黄灯10项、红灯4项。重大事件按编号去重，同一事项涉及多家机构只计一次，不将舆情线索直接纳入。

月度预警清单的监测类型分为经营、资本、风险；风险类指标按信用风险、市场风险、操作风险、流动性风险、声誉风险、集中度风险、战略风险、其他风险排列。清单展示中将合规、信息科技归入其他风险，经营和资本指标的风险分类显示为“—”，不改变原指标字典和首页矩阵分类。“当前状态”显示最新判定灯色，恢复正常的月内预警仍保留在原触发等级清单中，并单独显示处置状态，避免将恢复正常等同于办结。

机构顶部概览按指标ID去重统计资本及风险，不包含经营指标；经营指标仍可在下方选择查看。各类别指标总数等于当前红灯、黄灯、正常、缺数及超期数量之和。“本月曾预警”为当月有触发记录的不同指标数，不与当前亮灯数相加。零配置类别明确标注“未配置”，不视为正常。

“较上月新增”表示本月数量减上月数量的净差额，减少时显示减少、相等时显示持平。演示设置浦发银行自2026年7月、沪农商银行自2026年8月纳入范围，以验证机构数量和月份联动；不代表真实接入时间及项目实施安排。各月事件和预警是独立的虚构场景快照。

### 舆情与投资敞口

舆情条目将正面/负面/中性标签、唯一所属机构标签置于信息名称之前，放大名称及字段字体，重要程度、等级、发布时间各列显示，日期和时间在同一行展示。每条资讯只对应一个具体实体主体，不以行业资讯或多个主体的混合信息代替。详情展示该主体的信息来源、内容、核查状态、集团范围投资敞口、比例、样例客户排名和持有机构明细。同一主体的集团投资敞口可以涉及多家持有机构，但不因此增加该资讯的所属机构标签。当前演示包含6个客户主体，排名仅在样例客户范围内计算。

重大事件将机构标签和风险类型标签置于事项名称之前，处置状态、关注等级、上报时间各列显示；跨机构共同事项可保留多个涉及机构，但按事项编号去重。投资敞口采用样例投资账面余额，比例明确分母，不将授信额度、融资金额或监管风险暴露混称为投资敞口。

本次未提供真实重大风险事件报告及完整原始附件，新增报告正文、方案、岗位安排、日期和附件均为虚构样例，用于验证报告结构及交互，不代表机构事实、正式审批或已签署材料。待审议的方案标为草案，未完成的流程节点不显示已办理时间；未办结事项不展示已签署办结结论。相关指标按机构与风险类型匹配，仅供交叉核对，不推定事件由某条预警直接触发；实际损失与投资敞口分别展示。

### 指标类型配置

附件未明确各指标对应的“监测／管控”属性。本版为验证筛选交互配置了演示类型，不据此判定监管属性、授权责任或处置要求。正式接入时应由经确认的指标字典提供类型字段；类型、风险类别、机构适用范围与阈值版本分别管理，不以当前灯色推断指标类型。

## 数据和技术衔接

建议沿用“供数机构及既有系统 → 金控数仓 → 指标 / 规则 / 计算 / 阈值 / 预警 / 流程能力 → 统一门户与分层工作台”的路径。指标和数据质量信息通过已有能力中心获取，避免驾驶舱另建取数与加工口径。JDE、风险合规系统及其他既有系统具体提供哪些字段和服务，仍需依接口与源系统清单确认。

正式接入建议优先补齐：机构与主体主数据、指标唯一ID及适用范围、数据所属期与报送日历、内部阈值和监管约束的独立版本、统一客户与集团客户关系、业务资产及穿透层级、抵消与调整记录、预警事件与流程证据ID。上述字段决定“看得清、追得回、处置得了”能否真正形成闭环。

## 设计参考

共同客户融资归集、信息共享及风险隔离的设计，参考[《金融控股公司监督管理试行办法》](https://www.cncc.cn/zcfg/202203/t20220325_932.html)。

关联方及交易的穿透识别、并表范围审慎判断等设计，参考[《金融控股公司关联交易管理办法》](https://www.moj.gov.cn/pub/sfbgw/flfggz/flfggzbmgz/202306/t20230619_480997.html)。以上为设计参考，不替代项目适用范围、管理制度和验收基线的确认。
