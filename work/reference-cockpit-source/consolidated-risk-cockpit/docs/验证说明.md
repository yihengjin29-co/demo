# 源码整理与验证说明

## 本次验证范围

1. 分离当前页面的 HTML 框架、CSS 样式、JavaScript 及模拟数据，不调整页面功能和业务口径。
2. 按原顺序重新构建单文件 HTML，并与整理前当前版本进行逐字节比对。
3. 检查构建结果不包含本机绝对路径、外置脚本或外置样式依赖，并验证完整脚本可解析。
4. 执行月度预警分类测试，以及机构概览、重大事件报告、筛选与实际事件处理函数的逻辑测试。
5. 将交付压缩包解压到独立目录，再次构建并执行上述测试，核对交付包可独立使用。

## 业务测试重点

- 三个观察月份和四家机构的模拟范围联动。
- 预警清单八列分类、本月触发等级与当前灯色的区别，以及恢复正常但尚未办结的情形。
- 重大事件九列分类、跨机构事件按编号去重、八个报告章节、处置措施、六环节流程与附件预览。
- 机构资本指标及八类风险指标概览、当前状态分项合计、缺数与超期区分、统计数字下钻。
- 弹窗层级、筛选事件、报告附件返回位置与首页汇总数保持一致。

## 验证限制

本次测试采用 Node.js 虚拟运行环境及模拟浏览器对象，验证源码、生成内容和交互处理逻辑；不等同于重新进行真实浏览器视觉验收。`设计校核与使用说明.md` 中的历史浏览器尺寸检查记录来自原设计阶段。本次未重新核验各浏览器视觉效果，也不覆盖真实接口、安全、性能、权限或正式业务验收。
